# 🌿 Oasis Book Library

A free, open-source digital library built with React.js.

## Pages
- **Home** — Landing page with navigation
- **Category** — Browse 5 genres (Science, Historical, Biological, Novels, Mysteries)
- **Book Listings** — Book cards with descriptions, ratings, and download button
- **AudioBook** — Play/Pause audio books directly
- **About Us** — Library mission page
- **Contact Us** — Contact form with email validation

## How to Run

### Step 1 — Install dependencies
Open the folder in VS Code, then open the terminal and run:
```
npm install
```

### Step 2 — Start the app
```
npm start
```

The app will open at **http://localhost:3000**
